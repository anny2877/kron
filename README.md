# KRON – prototipo

## Ejecutar
```
cd kron-prototype
python3 -m http.server 8000
```
Abre http://localhost:8000

## Con Claude Code
```
cd kron-prototype
claude
```
o con Ollama: `ollama launch claude` (recomendado al menos 64k de contexto). Dentro de Claude Code ejecuta `/init`; ya existe `CLAUDE.md` con el contexto del proyecto.
